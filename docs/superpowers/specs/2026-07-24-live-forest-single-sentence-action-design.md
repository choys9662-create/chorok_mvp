# 라이브 포레스트 문장 기록 단일 버튼 설계

## 목표

문장 기록 카드의 두 액션을 하나의 `+` 버튼으로 통합한다. 사용자는 문장을 입력한 뒤 같은 버튼을 연속해서 사용하며, 첫 번째 탭에서는 생각 기록으로 자연스럽게 이어지고 두 번째 탭에서는 생각 작성 여부와 관계없이 기록을 마친다.

## 상호작용

1. 문장이 비어 있으면 `+` 버튼은 비활성화한다.
2. 문장을 입력하고 `+` 버튼을 처음 누르면 실제 저장 없이 문장을 확정하고 생각 입력 단계로 전환한다.
3. 생각 입력란에 자동으로 포커스를 준다.
4. 생각 입력 단계의 `+` 버튼을 누르면 다음 중 하나를 최종 저장한다.
   - 생각이 있으면 문장, 생각, 페이지를 함께 저장한다.
   - 생각이 비어 있으면 문장과 페이지만 저장한다.
5. 저장 완료 표시와 시트 닫힘 타이밍은 현재 동작을 유지한다.

## UI 범위

- 문장 입력 단계 우측 하단에는 `+` 버튼 하나만 둔다.
- 생각 입력 단계에서도 같은 위치와 형태의 `+` 버튼을 사용한다.
- 페이지 입력, 문장 미리보기 탭으로 돌아가기, 카드 크기와 전환 애니메이션, 키보드 인셋 처리는 변경하지 않는다.
- 디자인 앱과 실앱은 같은 `ChosuSheet`를 사용하므로 별도 UI 분기는 만들지 않는다.

## 데이터와 오류 처리

- 첫 번째 탭은 로컬 UI 상태 전환이며 `CollectedSentence`를 반환하지 않는다.
- 두 번째 탭에서만 기존 `_save` 경로를 사용해 `CollectedSentence`를 반환한다.
- 기존 저장 구조상 빈 생각은 빈 문자열로 유지한다.
- 문장 필수 조건과 기존 중복 탭 방지용 저장 완료 상태는 유지한다.

## 검증

- 문장 단계에 액션 버튼이 정확히 하나만 보이는지 확인한다.
- 첫 번째 탭이 생각 입력 단계로 전환하는지 확인한다.
- 생각을 쓰지 않고 두 번째 탭했을 때 빈 생각을 가진 문장이 반환되는지 확인한다.
- 생각을 쓴 뒤 두 번째 탭했을 때 문장과 생각이 함께 반환되는지 확인한다.
- 기존 OCR 사전 입력과 키보드 인셋 테스트가 계속 통과하는지 확인한다.
